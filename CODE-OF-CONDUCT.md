## Community Code of Conduct

Scope follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Instances of abusive, harassing, or otherwise unacceptable behavior
may be reported by contacting the project maintainer via GitHub issues or pull requests on [mario-ezquerro/scope](https://github.com/mario-ezquerro/scope).
